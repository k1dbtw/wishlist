# Вишлист

Личный вишлист с синхронизацией между телефоном и компьютером.

**Открыть:** https://claude.ai/artifact/SSH5APkw6xFdpBT9WLyHAW

Открой ссылку на телефоне (в приложении Claude или в браузере) и на компьютере — это один и тот же список, изменения появляются на обоих устройствах сразу.

## Как пользоваться

- Пиши желание одной строкой — ссылку и цену приложение вытащит само:
  - `AirPods Pro 25000`
  - `Кеды Converse https://… 7 990`
  - `Наушники Sony WH-1000XM5 32к`
  - просто ссылка → название возьмётся из домена
- Число в конце считается ценой, если оно ≥ 100 или с суффиксом (`к`, `тыс`, `₽`, `р`, `руб`). Поэтому `iPhone 16` останется названием.
- Три уровня «насколько хочется»: можно / хочу / очень.
- Кружок слева — «сбылось», желание уходит во вкладку «Сбылось».
- Нажми на желание — откроется редактирование (название, ссылка, цена, заметка, удаление с отменой).
- Сортировка: новые, важные, дорогие, дешёвые. Сверху — общая сумма.
- `/` на компьютере — фокус в строку добавления.

## Как устроено

Один файл `index.html` без сборки. Данные лежат в хранилище артефакта claude.ai (коллекция `wishes`, по документу на желание) и приходят на все устройства в реальном времени. Изменять список может только владелец; если поделиться ссылкой, другие смогут только смотреть.

Если открыть `index.html` просто в браузере (вне claude.ai), приложение работает в локальном режиме: всё сохраняется только в этом браузере, без синхронизации.
