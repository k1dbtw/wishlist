# stash

Деньги, дела и желания в одном месте. Всё записывается одной строкой, телефон и компьютер показывают одно и то же.

## Что внутри

**Деньги**
- одной строкой: `кофе 25к`, `такси 18 000 вчера`, `+8 млн зарплата` (валюта по умолчанию — узбекский сум, понимает «к», «тыс», «млн», «сум»): сумма, тип, категория и дата определяются сами
- категории расходов и доходов (свои названия и цвета), дата у каждой операции
- периоды: месяц, год, всё время, с листанием назад
- сводка: потрачено, доход, итог; бюджет на месяц с прогрессом
- графики: траты по дням или месяцам (с подсказкой при наведении или касании) и разбивка по категориям; нажми на категорию, и список отфильтруется
- экспорт операций в CSV (открывается в Excel и Google Таблицах)

**Дела**
- мысли и задачи одной строкой: `позвонить маме завтра #личное`, `отчёт в пт #работа`, `12.11`
- категории (Входящие, Работа, Личное, Идеи, Купить, можно свои), фильтр по категории
- группировка по категориям или по сроку (просрочено, сегодня, завтра, на неделе, позже) либо просто новые сверху
- закрепление, выполненные сворачиваются, можно очистить

**Хочу**
- вишлист со ссылками, ценами, приоритетом и заметками
- «сбылось» одним касанием и сразу предложение записать покупку в расходы
- подсказка, за сколько месяцев накопишь на всё при нынешнем темпе

**Продукт**
- аккаунты: регистрация по почте и паролю, у каждого свои данные
- синхронизация между устройствами, работа без интернета (записи уходят, когда появится сеть)
- ставится на телефон как приложение (PWA); на Android можно «поделиться» ссылкой из магазина прямо в вишлист
- светлая и тёмная тема, 6 цветов акцента
- смена пароля, «выйти на всех устройствах», экспорт всех данных в JSON, удаление аккаунта со всеми данными
- горячие клавиши на компьютере: `1` `2` `3` переключают разделы, `/` ставит курсор в строку ввода

## Деплой на Netlify

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/k1dbtw/wishlist)

Нажми кнопку, войди через GitHub и нажми **Deploy**. Больше ничего настраивать не нужно: аккаунты и данные хранятся во встроенном хранилище Netlify (Blobs).

Необязательные переменные окружения (Site configuration → Environment variables):

| переменная | зачем |
|---|---|
| `INVITE_CODE` | регистрация только по коду приглашения (для закрытой беты или личного использования) |
| `WISHLIST_KEY` | пароль от старой версии вишлиста: в настройках появится «перенести» старые желания в аккаунт |

## Разработка

```
npm install
npm run dev      # http://localhost:8888, данные лежат в .netlify/dev-data.json
```

Без сборки и фреймворков: фронтенд на нативных ES-модулях, сервер — одна функция Netlify.

```
index.html, styles.css          оболочка и стили (цвета — токены в :root)
js/app.js                       вход, вкладки, настройки, обновления
js/store.js                     локальная копия данных, офлайн-очередь, синхронизация
js/util.js                      разбор строк («кофе 25к вчера»), даты, деньги, диалоги
js/charts.js                    графики
js/views/*.js                   разделы: деньги, дела, хочу, настройки
netlify/functions/api.js        API: /api/auth/*, /api/sync, /api/account/*
server/auth.js                  пароли (scrypt), сессии в HttpOnly-cookie, блокировка перебора
server/data.js                  хранение и слияние записей (последняя правка побеждает, запись с проверкой ETag)
server/schema.js                проверка каждого поля, приходящего от клиента
dev/                            локальный сервер и хранилище для разработки
```

## Безопасность

- пароли хешируются scrypt с солью; после 8 неудачных попыток вход по почте блокируется на 15 минут
- сессия в HttpOnly + Secure + SameSite cookie, запросы на запись принимаются только как JSON с того же сайта
- строгий Content-Security-Policy, запрет встраивания во фреймы
- смена пароля завершает все остальные сессии
